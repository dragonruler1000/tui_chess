# tui_chess
A tui version of chess written in python

## Features
It is a pretty barebones version of chess right now. the only features that are working right now is moving trhe pieces according to the rules of chess and capturing pieces. also right now the only way to quit is ctrl+c (command+c on macos)
## Using
You can either download and use the [latest release](https://github.com/dragonruler1000/tui_chess/releases/latest) (linux need to launch it via a terminal) or clone the repo:
```
git clone https://github.com/dragonruler1000/tui_chess.git | cd tui_chess
```
make an venv
```
python -m venv .venv
```
then install the requirements:
```
pip install -r requirements.txt
```
then run main.py
```
python main.py
```
